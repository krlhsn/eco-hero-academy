# Original 2025 console source

The original Code in Place 2025 single-file Python program is preserved here as `original_2025_console.py.gz` to keep the historical snapshot compact. It is not the maintained implementation; the refactored package lives in `../eco_hero/`.

To restore the original source file, run `gzip -dk original_2025_console.py.gz` from this directory. The original advisor uses keyword/rule matching; it is not a generative AI implementation. Some original recycling facts and named regional presets have not been independently verified.
