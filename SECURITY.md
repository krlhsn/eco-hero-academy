# Security policy

## Supported version

The current `main` branch is the supported version.

## Reporting a concern

Please report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature when available. Do not publish profile files, personal data or exploit details in a public issue.

## Local data

Profiles are stored in a local JSON file without password protection or encryption. Do not share the file if it contains information you consider private. Use non-identifying usernames.
